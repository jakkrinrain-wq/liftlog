# 🏋️ LiftLog — แอปบันทึกเวทเทรนนิ่งส่วนตัว

แอปบันทึกการเล่นเวทสำหรับมือถือ (Android) ออกแบบให้ใช้ในยิมโดย**คิดน้อยที่สุด**
เปิดแอป → กดเริ่ม → ยก → กดเสร็จ → พัก → ทำซ้ำ

- **ข้อมูลเก็บในมือถือของคุณเท่านั้น** ไม่มีเซิร์ฟเวอร์ ไม่ต้องสมัครสมาชิก
- **ใช้ได้แม้ไม่มีเน็ต** หลังเปิดครั้งแรก

---

## ✨ ฟีเจอร์

### เล่นง่าย คิดน้อย
- **เล่นวนตามลำดับ** Push → Pull → Legs เว้นไปกี่วันก็ได้ แอปจำเองว่าครั้งต่อไปเล่นอะไร หรือจะตั้งตามวันในสัปดาห์ก็ได้
- **โหมดทีละเซ็ต** จอแสดงแค่เซ็ตที่กำลังเล่น ตัวเลขใหญ่ ปรับด้วยปุ่ม − / + ไม่ต้องพิมพ์
- **ใส่น้ำหนักให้อัตโนมัติ** จำตัวเลขครั้งก่อน และเพิ่มน้ำหนักให้เองเมื่อทำครบ 12 ครั้งทุกเซ็ต (ใช้หลักเพิ่มจำนวนครั้งก่อน แล้วค่อยเพิ่มน้ำหนัก)
- **จับเวลาพักเต็มจอ** เริ่มเองเมื่อกดเสร็จเซ็ต หมดเวลามือถือจะสั่นและมีเสียง พร้อมบอกเซ็ตต่อไป
- **กันจอดับ** ตลอดเวลาที่เล่นอยู่
- **ถามเองว่า "จบเลยไหม?"** เมื่อเล่นครบทุกเซ็ต พร้อมหน้าสรุป (เวลา เซ็ต น้ำหนักรวม สถิติใหม่ 🏆)

### คลังท่า + หุ่นสาธิต
- **1,398 ท่า** แบ่งหมวด อก / หลัง / ขา / ไหล่ / แขน / หน้าท้อง กรองตามอุปกรณ์ได้
- **หุ่นกายวิภาคสาธิตท่า** ทุกท่า โดย 24 ท่าหลักเป็นวิดีโอชัด (ขยายด้วย AI) ปรับความเร็วได้ และดูได้แม้ไม่มีเน็ต
- **แผนที่กล้ามเนื้อหน้า-หลัง** บอกกล้ามหลักและกล้ามรองที่ท่านั้นใช้
- **วิธีเล่นภาษาไทย** สำหรับท่าหลัก และมีลิงก์ไปหาคลิปสอนใน YouTube

### ติดตามความก้าวหน้า
- **หุ่นความพร้อมของกล้ามเนื้อ** ในหน้าแรก กล้ามแต่ละส่วนเปลี่ยนสีตามการฟื้นตัว 🟢 พร้อม · 🟡 กำลังฟื้น · 🟠 ยังล้า
- **กราฟ** จำนวนครั้งที่เล่นต่อสัปดาห์ น้ำหนักสูงสุดรายท่า 1RM โดยประมาณ และน้ำหนักตัว
- **คำนวณจานน้ำหนัก** บอกว่าต้องใส่จานข้างละกี่แผ่น

### ข้อมูลปลอดภัย
- **สำรองข้อมูล** เป็นไฟล์ แล้วส่งเข้า Google Drive หรือ LINE ของตัวเองได้ และกู้คืนจากไฟล์ได้
- **เตือนให้สำรอง** ถ้าไม่ได้สำรองเกิน 7 วัน

## 🚀 ลองเปิดในคอม
ต้องมี Python ในเครื่อง จากนั้นรันคำสั่งนี้ในโฟลเดอร์โปรเจกต์:

```bash
py -m http.server 8765
```

แล้วเปิด Chrome ไปที่ `http://localhost:8765` และกด F12 → เลือกโหมดมือถือ เพื่อดูขนาดเท่าจอโทรศัพท์

## 📱 ติดตั้งลงมือถือ (Android)
1. ฝากโฟลเดอร์นี้บนเว็บที่ใช้ HTTPS เช่น GitHub Pages หรือ Netlify
2. เปิดลิงก์ด้วย Chrome บนมือถือ
3. กด ⋮ → **เพิ่มลงในหน้าจอหลัก**

> ถ้าเว็บฝากหายไปในภายหลัง แอปที่ติดตั้งแล้วยังใช้ได้ และข้อมูลยังอยู่ในมือถือ
